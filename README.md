# ピコのコード島（code-lab）

ブロックをならべてロボットの「ピコ」を動かす、Scratchの手前のプログラミングパズル。「おうちラボ」の1つ。

## レベル構成（全11面）
- 1しょう じゅんばん（1〜4）：すすむ・みぎ／ひだりを むく を順に並べる
- 2しょう くりかえし（5〜8）：ブロック数の上限つき。8は二重ループ
- 3しょう もしも（9〜11）：「ゴールに つくまで くりかえす」＋「もしも まえが かべ／よこに みちが ある」

ブロックの色はScratchと同じ（動き＝青、制御＝オレンジ、調べる＝水色）。「Scratchの ことば」ボタンでScratchのブロック名を併記、各章クリア時に対応表を表示します。進み具合はブラウザ（localStorage）に保存。
